# 🤖 쓰담쓰담: 수원역 대청소

수원역 광장을 지키는 자율주행 쓰레기 수거·단속 로봇 **쓰담쓰담(SSUDAM-SSUDAM)** 을 조종해 쓰레기를 치우고 무단투기자를 시원하게 처리하는 2.5D 아케이드 웹 게임입니다!

## 🎮 플레이 링크
- **GitHub Pages**: https://leeseungsang.github.io/ssudam-game/

## 🕹️ 조작 방법
### PC (키보드 + 마우스)
- **이동**: `WASD` 또는 `방향키`
- **로봇팔 조준**: 마우스 커서 이동
- **집기 / 던지기**: `마우스 좌클릭` 또는 `Space` (길게 누르면 파워 투척)
- **스킬**: `Q` (🌀 청소기) · `E` (🧹 조력자 환경미화원)
- **일시정지**: `P` 또는 `Esc`

### 스마트폰 / 태블릿 (터치)
- **왼손**: 화면 왼쪽 터치 & 드래그 (가상 조이스틱)
- **오른손**: 짧은 탭(자동 집기/던지기) · 드래그 후 떼기(방향 조준 투척)
- **스킬**: 화면 하단 중앙 `🌀 청소기` / `🧹 조력자` 버튼 터치

## 🌟 주요 기능
- **8단계 순차 해금 캠페인 + 24시간 무한가동 (경쟁전)**:
  1. 한가한 낮 → 2. 출근시간 → 3. 여행 가는 사람들 → 4. 퇴근시간(노을) → 5. 술마시러 가는 길 → 6. 술취해서 텐션 UP → 7. 불금 → 8. 할로윈 파티
  - 무한가동 (경쟁전)에서 1~30등 글로벌 순위표 도전! (1등 금·적색 왕관 장식, 1~3등 금은동, 1~10등 월계수 잎 장식)
- **게임 전환 포털**: 좌측 상단 버튼을 통해 [AI 로봇팔 수박게임](https://leeseungsang.github.io/dlro-s_game/)과 양방향 이동 가능
- **스킬 2종**:
  - **🌀 청소기 (최대 3회 / 시작 2회 / 투기자 처치 시 10% 충전)**: 5초간 차체 주변 쓰레기를 자동 흡입 제거
  - **🧹 조력자 (최대 2회 / 시작 1회 / 인간쓰레기통 처리 시 1% 충전)**: 주간 주황복·야간 형광복을 입은 환경미화원분들이 나무자루 초록 싸리빗을 들고 오른쪽→왼쪽으로 광장 전체를 싹쓸이!
- **시민 오인 검거 반격**: 일반시민을 잡으면 화를 내며 쓰레기를 던진 뒤 현행범(`!`)으로 전환
- **테마별 복장·쓰레기 & 특수 기믹**: 여권/신분증/미니호박(2배 점수), 6단계 머리띠 넥타이 취객 & 미끄러운 토사물, 8단계 투명 유령 & 호박 보스 사탕 폭탄
