# 🤖 쓰담쓰담: 수원역 대청소

수원역 광장을 지키는 자율주행 쓰레기 수거·단속 로봇 **쓰담쓰담(SSUDAM-SSUDAM)** 을 조종해 쓰레기를 치우고 무단투기자를 시원하게 처리하는 2.5D 아케이드 웹 게임입니다!

## 🎮 플레이 링크
- **GitHub Pages**: https://leeseungsang.github.io/ssudam-game/

## 🕹️ 조작 방법
### PC (키보드 + 마우스)
- **이동**: `WASD` 또는 `방향키`
- **로봇팔 조준**: 마우스 커서 이동
- **집기 / 던지기**: `마우스 좌클릭` 또는 `Space`
  - 짧게 클릭: 즉시 집기 / 커서 방향으로 가볍게 던지기
  - 길게 누르고 떼기: 궤적 가이드를 보며 파워 투척
- **일시정지**: `P` 또는 `Esc`

### 스마트폰 / 태블릿 (터치)
- **왼손**: 화면 왼쪽 아무 곳이나 터치 & 드래그 (가상 조이스틱)
- **오른손**:
  - **짧게 탭**: 가까운 쓰레기·무단투기자 자동 집기 / 수거함·인간쓰레기통·광장 밖으로 스마트 투척
  - **드래그 후 떼기**: 원하는 방향으로 직접 조준 파워 투척!

## 🌟 게임 특징
- **다관절 로봇팔(IK) & 그리퍼**: 실제로 꺾이고 집는 로봇팔 액션과 표정 LED 눈 변화
- **스피드 쓰레기 수거**: 3색 스마트 분리수거함에 가까이 가거나 원거리 슛(`나이스 슛!`)으로 콤보 & 피버 게이지 충전
- **병맛 무단투기자 처리**: 쓰레기를 버리고 도망치는 `!` 현행범을 집어서 **「인간쓰레기통」** 에 덩크하거나 **광장 밖으로 홈런 투척**!
- **스테이지 & 무한 모드**: 출근길 → 점심시간 → 불금 야간 수원역 스테이지와 24시간 무한가동 모드
- **과부하 시스템**: 쓰레기가 일정량 이상 쌓이면 쓰담쓰담이 과부하로 스파크를 튀기며 고장(Game Over)!
